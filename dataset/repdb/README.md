# RepDB — catalogo locale

Exercise data by [RepDB (repdb.co)](https://repdb.co).

Fonte: https://github.com/RepDB/exercise-dataset

Snapshot scaricato il 2026-10-03: 609 esercizi. File originali in `raw/`, esclusi da Git; hash e URL nel manifest. Uso nell'app con attribuzione consentito; redistribuzione come dataset o API vietata dalla licenza salvata in `raw/LICENSE-DATA.md`. Nessuna immagine scaricata.

Campi utili: MET, difficoltà, muscoli primari e secondari, attrezzatura, categorie, obiettivi e istruzioni. Tutti i 609 record hanno un MET numerico; la verifica di struttura non valida l'accuratezza fisiologica. Non sono disponibili punteggi quantitativi validati di ipertrofia, dimagrimento o aderenza personale.

Il catalogo include `inverted-row`. Il livello dichiarato è intermediate, mentre Free Exercise DB indica beginner: conservare le fonti distinte e modellare separatamente posizione, appoggio dei piedi e carico effettivo. Aqua bag/tank richiedono verifica della copertura e probabili estensioni personali.
